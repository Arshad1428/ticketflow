# Delivery scope and BRD traceability

This ZIP is a working initial-release implementation, with source, reproducible dependency locks, migrations, tests, Docker packaging and selected product features. It is not a fully certified commercial release. The BRD includes future phases and measurable nonfunctional targets that require a pilot and deployment validation.

## Nonfunctional implementation and remaining validation

- Implemented: TOTP MFA with encrypted enrollment secrets and account-level session revocation; bcrypt password hashing; same-site HTTP-only cookies; role and row-access checks; parameterized SQL; schema validation; security headers; rate limits; upload size/type/signature validation; optional ClamAV with fail-closed enforcement; immutable audit trigger; persistent worker state and outbox.
- Production infrastructure must provide HTTPS and encrypted database/file volumes. No application-managed encryption of ticket bodies is supplied.
- Password recovery email, localisation, configurable date formats, retention/deletion schedules, legal compliance assessment and operational monitoring are not implemented.
- Attachments must be scanned by enabling ClamAV for production. No claim is made that MIME validation alone detects malicious documents.
- 50 concurrent staff / 500 clients, sub-three-second pages, 99.5% availability and 95% SLA achievement have **not** been load-tested or operationally proven.
- Outbox delivery is at least once. SMTP configuration is installation-specific. Incoming messages create new tickets and do not thread email replies.
- The sample installation is one database per customer. It does not implement SaaS billing, self-service registration, AI auto-resolution, live chat, voice or native mobile apps, consistent with the BRD exclusions.

Before paid deployment, complete the listed hardening items, pilot the SLA calendar against your actual service contracts, run a real PostgreSQL/container smoke test and load test, and configure the external services. The supplied tests are reproducible and described in README.
